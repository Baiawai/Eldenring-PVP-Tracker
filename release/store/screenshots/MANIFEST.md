# Localized Store screenshot drafts

**Superseded draft: version 1.1.0.0. Do not use for the 1.0.10.0 release.**
The replacement images are in `../screenshots-1.0.10.0/`.

Generated from the development app with a private temporary profile at 1920 × 1080. There are no real accounts, player names, captures, or match results. The game and Steam were not accessed; external network requests were blocked. The guide, overlay settings, language settings and empty statistics are real UI views. These are draft images for visual and Store compliance review; they are not screenshots of a built or installed MSIX and are not submitted to the Store. Game-language detection is mocked to English; all interface languages are selected through the normal local settings UI.

Each directory contains `01-guide.png`, `02-overlay-settings.png`, `03-language-settings.png`, and `04-statistics.png`. Review each image and map these interface locales to the Store listings actually enabled in Partner Center before submission.
