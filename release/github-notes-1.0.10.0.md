# Elden PVP Tracker 1.0.10.0

## Français (fr-FR)

- Un overlay personnalisable affiche en jeu l’état du suivi, le mode et les joueurs Steam détectés avec leur ping lorsqu’il est disponible.
- Les cartes P2P présentent les avatars Steam, la durée de connexion et le nombre de rencontres enregistrées localement.
- Choisissez séparément les langues de l’interface et du jeu. De nouvelles langues sont disponibles pour l’interface et la reconnaissance des événements a été améliorée.
