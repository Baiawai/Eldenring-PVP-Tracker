# Notes de version 1.0.6.0

Corrections depuis la version Microsoft Store 1.0.5.0.

## Français (fr-FR)

- Correction d’une erreur d’initialisation au premier lancement de la version Microsoft Store, liée à la redirection des fichiers par Windows.
- Amélioration de la restauration d’une clé de données lorsque Windows redirige les fichiers ; une copie de sécurité de la clé précédente est conservée.

## English (en-US)

- Fixed an initialization error on the first launch of the Microsoft Store version caused by Windows file redirection.
- Improved data-key recovery when Windows redirects files; a backup of the previous key is retained.

## Deutsch (de-DE)

- Ein Initialisierungsfehler beim ersten Start der Microsoft-Store-Version durch Windows-Dateiumleitung wurde behoben.
- Die Wiederherstellung des Datenschlüssels bei umgeleiteten Dateien wurde verbessert; eine Sicherung des vorherigen Schlüssels bleibt erhalten.

## Italiano (it-IT)

- Corretto un errore di inizializzazione al primo avvio della versione Microsoft Store causato dal reindirizzamento dei file di Windows.
- Migliorato il ripristino della chiave dati con file reindirizzati; viene conservata una copia della chiave precedente.

## Español de España (es-ES)

- Corregido un error de inicialización en el primer inicio de la versión de Microsoft Store causado por la redirección de archivos de Windows.
- Mejorada la recuperación de la clave de datos con archivos redirigidos; se conserva una copia de la clave anterior.

## Español de Latinoamérica (es-419)

- Se corrigió un error de inicialización al abrir por primera vez la versión de Microsoft Store, causado por la redirección de archivos de Windows.
- Se mejoró la recuperación de la clave de datos con archivos redirigidos; se conserva una copia de la clave anterior.

## Português (pt-BR)

- Corrigido um erro de inicialização na primeira execução da versão Microsoft Store causado pelo redirecionamento de arquivos do Windows.
- Melhorada a recuperação da chave de dados com arquivos redirecionados; uma cópia da chave anterior é mantida.

## Polski (pl-PL)

- Naprawiono błąd inicjalizacji przy pierwszym uruchomieniu wersji Microsoft Store spowodowany przekierowaniem plików przez Windows.
- Ulepszono odzyskiwanie klucza danych przy przekierowanych plikach; kopia poprzedniego klucza zostaje zachowana.

## Русский (ru-RU)

- Исправлена ошибка инициализации при первом запуске версии Microsoft Store, вызванная перенаправлением файлов Windows.
- Улучшено восстановление ключа данных при перенаправлении файлов; резервная копия предыдущего ключа сохраняется.

## 日本語 (ja-JP)

- WindowsのファイルリダイレクトによりMicrosoft Store版の初回起動時に初期化が失敗する問題を修正しました。
- ファイルがリダイレクトされた場合のデータキー復元を改善し、以前のキーのバックアップを保持します。

## 한국어 (ko-KR)

- Windows 파일 리디렉션으로 인해 Microsoft Store 버전의 첫 실행에서 초기화가 실패하는 문제를 수정했습니다.
- 파일이 리디렉션될 때 데이터 키 복구를 개선하고 이전 키의 백업을 보존합니다.

## 简体中文 (zh-CN)

- 修复 Windows 文件重定向导致 Microsoft Store 版本首次启动时初始化失败的问题。
- 改进文件重定向时的数据密钥恢复，并保留先前密钥的备份。

## 繁體中文 (zh-TW)

- 修正 Windows 檔案重新導向導致 Microsoft Store 版本首次啟動時初始化失敗的問題。
- 改善檔案重新導向時的資料金鑰復原，並保留先前金鑰的備份。

## ไทย (th-TH)

- แก้ไขข้อผิดพลาดในการเริ่มต้นครั้งแรกของเวอร์ชัน Microsoft Store ที่เกิดจากการเปลี่ยนเส้นทางไฟล์ของ Windows
- ปรับปรุงการกู้คืนคีย์ข้อมูลเมื่อ Windows เปลี่ยนเส้นทางไฟล์ โดยเก็บสำเนาคีย์เดิมไว้

## العربية (ar-SA)

- إصلاح خطأ في التهيئة عند التشغيل الأول لإصدار Microsoft Store بسبب إعادة توجيه الملفات في Windows.
- تحسين استعادة مفتاح البيانات عند إعادة توجيه الملفات، مع الاحتفاظ بنسخة احتياطية من المفتاح السابق.
