# Notes de version 1.0.7.0

Modifications depuis la version Microsoft Store 1.0.6.0.

## Français (fr-FR)

- La zone des notifications se stabilise automatiquement après la reconnaissance d’un message sur deux lignes ; la détection reprend si la fenêtre du jeu ou l’écran change.
- La mesure avancée du ping Steam peut demander une autorisation administrateur Windows ; en cas de refus, le ping Steam reste utilisé lorsqu’il est disponible.
- Les particules de la page principale sont désormais actives dans la version Store.
- Ouverture au choix dans le navigateur ou dans une fenêtre dédiée, avec une adresse locale simplifiée.
- Connexion Steam au classement simplifiée, avec confirmation automatique lorsque le navigateur le permet et diagnostics améliorés.
- Reprise unique des statistiques locales existantes dans le classement et synchronisation des nouveaux combats.
- Présentation du profil et des statistiques améliorée.

## English (en-US)

- The notification area is fixed automatically after a recognized two-line message; detection resumes when the game window or display changes.
- Advanced Steam ping measurement may request Windows administrator permission; if declined, Steam ping is used when available.
- Home-page particles are now enabled in the Store version.
- Choose between a browser and a dedicated window, with a simpler local address.
- Simpler Steam leaderboard sign-in, with automatic confirmation when supported and improved diagnostics.
- Existing local statistics are imported once into the leaderboard; new fights are synchronized.
- Improved profile and statistics presentation.

- Die erweiterte Steam-Ping-Messung kann Windows-Administratorrechte anfordern; bei Ablehnung wird der verfügbare Steam-Ping verwendet.
- Die Partikel auf der Startseite sind nun in der Store-Version aktiviert.
- Wahl zwischen Browser und eigenem Fenster mit vereinfachter lokaler Adresse.
- Einfachere Steam-Anmeldung für die Rangliste mit automatischer Bestätigung, sofern unterstützt, und besseren Diagnosemeldungen.
- Vorhandene lokale Statistiken werden einmalig in die Rangliste übernommen; neue Kämpfe werden synchronisiert.
- Verbesserte Darstellung von Profil und Statistiken.
