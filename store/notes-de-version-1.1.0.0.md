# Notes de version 1.1.0.0

Préparation pour la mise à jour Store : comparer avec la dernière version effectivement publiée dans Partner Center avant soumission. La version 1.0.6.0 est installée sur la machine de développement, mais cela ne prouve pas qu’elle est la dernière version publiée. Chaque section ci-dessous est un texte distinct à copier dans « Nouveautés de cette version » ; l’introduction et les titres ne font pas partie de ce champ.

## Français (fr-FR)

- Un overlay personnalisable affiche en jeu l’état du suivi, le mode et les joueurs Steam détectés avec leur ping lorsqu’il est disponible.
- Les cartes P2P présentent les avatars Steam, la durée de connexion et le nombre de rencontres enregistrées localement.
- Choisissez séparément les langues de l’interface et du jeu. De nouvelles langues sont disponibles pour l’interface et la reconnaissance des événements a été améliorée.

## English (en-US)

- A customizable in-game overlay shows tracking status, mode, and detected Steam players with their ping when available.
- Redesigned P2P cards show Steam avatars, connection duration, and locally recorded encounter counts.
- Choose interface and game languages separately. More interface languages are available, and event recognition has been improved.
