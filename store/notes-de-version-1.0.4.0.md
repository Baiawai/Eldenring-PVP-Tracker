# Notes de version 1.0.4.0 — brouillon

Textes à vérifier sur le paquet Store 1.0.4.0 et à ajuster avant publication. Cette version n'est pas encore publiée.

## Français (fr-FR)

- Le classement s'affiche automatiquement après acceptation des conditions de participation. Les profils peuvent être signalés sur Discord.
- Une notification facilite l'accès à l'inscription au classement. Les notifications du volet droit sont entièrement cliquables et accessibles au clavier.
- La version Store utilise le classement sur eldenringpvp.com. Les anciennes connexions peuvent être conservées lors du passage au serveur public.
- Amélioration de l'activation du journal Steam lorsque Steam nécessite des droits administrateur. Windows peut demander une autorisation.

## English (en-US)

- The leaderboard is displayed automatically after you accept the participation terms. Player profiles can be reported on Discord.
- A notification makes it easier to join the leaderboard. Right-hand notifications are fully clickable and keyboard accessible.
- The Store version uses the leaderboard at eldenringpvp.com. Previous connections can be preserved when switching to the public server.
- Improved Steam logging activation when Steam requires administrator rights. Windows may ask for permission.

- Die Store-Version verwendet die Rangliste auf eldenringpvp.com. Frühere Verbindungen können beim Wechsel zum öffentlichen Server erhalten bleiben.
- Die Aktivierung des Steam-Protokolls wurde verbessert, wenn Steam Administratorrechte benötigt. Windows kann eine Bestätigung anfordern.
