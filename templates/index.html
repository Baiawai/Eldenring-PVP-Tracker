FAQ

Informations

Comment démarrer le suivi ?

Lance le tracker et Elden Ring. Vérifie que la langue choisie correspond à celle du jeu, puis clique sur Start. Stop arrête le suivi ; le redémarrer remet la session en mémoire à zéro.

Le jeu doit-il rester visible ?

Garde Elden Ring au premier plan pendant la détection. Les notifications masquées ou absentes ne peuvent pas être lues.

Quels modes sont suivis ?

L’arène 1v1, les invasions et les défenses sont séparées. Les égalités concernent uniquement l’arène.

Pourquoi un résultat manque-t-il ?

Le tracker lit les notifications à l’écran par reconnaissance de texte (OCR). Un message masqué, manqué ou mal lu peut laisser un résultat inconnu. Vérifie la langue du jeu et la zone dans Configuration → Capture, puis teste-la avec un exemple reconnu sur deux lignes.

Comment choisir la langue ?

Au premier lancement, le tracker utilise automatiquement la langue du navigateur si elle est prise en charge, sinon l’anglais. Tu peux la modifier dans Configuration pour qu’elle corresponde à celle du jeu : elle règle l’interface et la reconnaissance des notifications sans changer la langue du jeu. Ton choix est conservé.

Comment régler les captures ?

La détection de la zone des notifications est automatique par défaut. Dans Configuration → Capture, vérifie l’aperçu avec une notification reconnue sur deux lignes. Une fois la zone correctement calibrée, il est fortement conseillé de la verrouiller : ses limites restent fixes et une détection automatique erronée ne peut pas les modifier. Déverrouille-la si l’affichage du jeu ou la position des notifications change, ou désactive le mode automatique pour régler les limites manuellement. Un intervalle plus long peut faire manquer des notifications brèves.

Comment lire les statistiques ?

Choisis un mode : le taux de victoire divise les victoires par les victoires, défaites et égalités enregistrées. Les égalités ne concernent que l’arène. Le graphique utilise les captures de résultats conservées ; il peut donc différer des statistiques cumulées.

Que montre la page Joueurs ?

Elle regroupe les noms reconnus et les profils Steam observés. Un nom de personnage et un profil Steam ne sont pas automatiquement associés.

Comment fonctionne le ping ?

Les informations Steam et le ping apparaissent lorsqu’ils sont disponibles. Une adresse peut être celle d’un relais et sa localisation reste indicative. En développement, la mesure avancée du ping peut demander une autorisation administrateur ; la version Store utilise le ping Steam disponible sans élévation.

Où sont mes données ?

Les statistiques, réglages, captures et historiques sont stockés sur ton PC. Sauvegarde le dossier %APPDATA%\Elden Ring PvP Tracker lorsque le tracker est arrêté.

Le classement est-il disponible ?

Pour afficher les joueurs dans l’application, active la participation et accepte les conditions. Le classement utilise le serveur configuré, par défaut eldenringpvp.com. La participation est facultative et nécessite un compte Steam.

Faut-il installer Python ou Tesseract ?

La version Store comprend les composants nécessaires. Pour lancer le projet depuis ses sources, installe Python et prépare la distribution locale de Tesseract ou utilise une installation existante ; consulte le README du projet.

Fermer l’onglet arrête-t-il le suivi ?

Fermer l’onglet laisse le tracker actif. Stop arrête le suivi ; Configuration → Quitter ferme le programme. Redémarrer le suivi remet la session en mémoire à zéro, mais conserve les statistiques enregistrées.

Comment protéger mes informations ?

Les captures et historiques peuvent contenir des noms ou adresses réseau. Protège tes sauvegardes avant de les partager.

Comment récupérer mon profil de personnage ?

Dans Configuration → Profil, lance la capture. En jeu, ouvre Configuration → Quitter la partie sans confirmer la sortie et garde le jeu visible. Le tracker récupère ensemble pseudo, niveau et image : vérifie-les avant d’enregistrer ou annule si nécessaire.

Comment fonctionnent l’archivage et la purge de l’historique ?

Arrête le suivi avant d’archiver ou de purger l’historique actif. L’archivage retire les événements de la liste, y compris les rencontres Steam, et les conserve chiffrés localement. La restauration ajoute les événements absents sans doublons et conserve l’archive. La purge retire l’historique actif mais conserve les archives, les captures et les statistiques cumulées.

Comment activer la détection Steam ?

Dans Configuration → P2P, active la détection des joueurs. L’activation automatique du journal Steam est proposée par défaut : elle demande à Steam d’activer le journal nécessaire au démarrage du tracker ou de Steam. Si elle échoue, la commande manuelle reste disponible. Les profils observés ne sont pas automatiquement associés aux personnages en jeu.

Comment connecter Steam et participer au classement ?

Dans Configuration → Classement en ligne, active la participation et accepte les conditions. Connecte-toi à Steam dans la fenêtre ouverte, puis saisis dans le tracker le code temporaire affiché par le site ; ne partage pas ce code. La publication d’un lien vers ton profil Steam est facultative.
