FAQ

Informations

Comment démarrer le suivi ?

Lance le tracker et Elden Ring, puis clique sur Start. Stop arrête le suivi.

Le jeu doit-il rester visible ?

Garde Elden Ring au premier plan pendant la détection. Les notifications masquées ou absentes ne peuvent pas être lues.

Quels modes sont suivis ?

L’arène 1v1, les invasions et les défenses sont séparées. Les égalités concernent uniquement l’arène.

Pourquoi un résultat manque-t-il ?

La reconnaissance lit les messages à l’écran et peut se tromper. Vérifie la langue du jeu et la zone des notifications.

Comment choisir la langue ?

Dans les paramètres, sélectionne la langue utilisée dans le jeu. Le réglage adapte l’interface et la reconnaissance, pas le jeu lui-même.

Comment régler les captures ?

Dans les paramètres, adapte la zone des notifications et l’intervalle de capture. Une prévisualisation apparaît quand le jeu est capturé.

Comment lire les statistiques ?

Choisis un mode. Le taux de victoire utilise les résultats connus ; le graphique utilise les captures de résultats enregistrées.

Que montre la page Joueurs ?

Elle regroupe les noms reconnus et les profils Steam observés. Un nom de personnage et un profil Steam ne sont pas automatiquement associés.

Comment fonctionne le ping ?

Les informations Steam et le ping ne sont affichés que s’ils sont disponibles. Une adresse peut être celle d’un relais.

Où sont mes données ?

Les statistiques, réglages, captures et historiques sont stockés sur ton PC. Sauvegarde le dossier %APPDATA%\Elden Ring PvP Tracker lorsque le tracker est arrêté.

Le classement est-il disponible ?

Le classement distant est désactivé dans la version Store. La version de développement conserve l’ancien service, qui peut être indisponible.

Faut-il installer Python ou Tesseract ?

Pour la version Store, non. Pour exécuter le projet depuis ses sources, Python et Tesseract doivent être installés.

Fermer l’onglet arrête-t-il le suivi ?

Non. Pour arrêter le programme, utilise le bouton prévu dans les paramètres. La session en mémoire repart de zéro au redémarrage.

Comment protéger mes informations ?

Les captures et historiques peuvent contenir des noms ou adresses réseau. Protège tes sauvegardes avant de les partager.

    Choisir votre pseudo

    Saisissez de préférence le pseudo utilisé dans le jeu.

    1. – Au moins 3 caractères.
    2. – 16 caractères maximum.
    3. – Lettres non accentuées et chiffres uniquement.

    Le pseudo est enregistré automatiquement lorsqu’il respecte ces conditions.

    Capturer l’avatar du personnage

    1. Clique sur « Commencer » : le suivi démarre automatiquement si nécessaire.
    2. Dans Elden Ring, ouvre le menu, puis Configuration et l’onglet « Quitter la partie », sans confirmer la sortie.
    3. Reste sur cet écran quelques secondes, puis reviens dans le tracker.

    La photo est enregistrée automatiquement dès sa capture. Vérifie l’aperçu, puis clique sur « Terminer ».

    Avatar enregistré automatiquement.

    Relever le niveau du personnage

    1. Clique sur « Commencer » : le suivi démarre automatiquement si nécessaire.
    2. Dans Elden Ring, ouvre le menu, puis Configuration et l’onglet « Quitter la partie », sans confirmer la sortie.
    3. Reste sur cet écran quelques secondes, puis reviens dans le tracker.

    Le niveau est enregistré automatiquement dès sa lecture. Vérifie le résultat, puis clique sur « Terminer ».

    Niveau enregistré automatiquement.
